# Images

Images belong to the **text**, not to any one edition. Every edition of a manuscript works on the
same images, which is what makes two editions of the same fragment comparable.

## Uploading

In [Manage](/editor/opening) → **Texts** → **Images**, use **Upload**, or drag files onto the drop
zone. JPEG, PNG, TIFF, GIF, and BMP are accepted. Several files can go at once; each shows its own
progress, and a failed upload can be retried or dismissed without disturbing the others.

Uploaded images are tiled for deep zoom, so a large plate can be inspected at full resolution
without the whole file being downloaded.

## Naming and ordering

Each image card carries its name, a pencil to edit it, and a trash icon.

**Editing** an image gives you **Name** (required) and **Description**. The name is what identifies
the image in the Editor's image bar, so a systematic scheme — `RS22-02_1`, `RS22-02_2` — is worth
keeping to.

**Reordering** is done by dragging a card by the grip at the left of its name. The order set here is
the order the images appear in, in both the Editor and the Viewer, so it should follow the physical
sequence of the manuscript.

## Deleting

The trash icon deletes an image. The confirmation warns you when akṣaras have been drawn on it,
because those akṣaras go with it — in every edition of the text, not just the one you have open.
This cannot be undone.

## When changes appear in the workspace

The image pane behind the dialog is not updated while Manage is open. Uploads, renames, reorders,
and deletions are all picked up in one go when you close it.

## Working across several images

When a text has more than one image, an image bar appears in the workspace for moving between them.
Akṣaras belong to the image they were drawn on, so the akṣara table shows the current image's signs
only — the count in the akṣara editor is for the whole edition.

Tokens, by contrast, can span images. Selecting a token whose akṣaras are on another image switches
the workspace to that image automatically.
