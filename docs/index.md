## Which guide do I need?

**Reading a manuscript?** Start with the [Viewer guide](/viewer/). It covers navigating images,
following a transliteration, and using the glossary and paleography tools.

**Creating an edition?** Start with the [Editor guide](/editor/). It covers accounts, uploading
images, transcription, lexical work, and publication.

Both guides assume the vocabulary explained in [Core Concepts](/concepts/). If a term is unfamiliar,
check the [glossary](/reference/glossary).
