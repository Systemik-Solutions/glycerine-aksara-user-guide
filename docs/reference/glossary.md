# Glossary

Terms used across the Viewer and the Editor.

::: info Work in progress
Definitions below are placeholders and need review by a subject-matter editor before publication.
:::

## Aksara

The basic unit of the Kharoṣṭhī writing system: a consonant with its inherent or marked vowel. See
[Aksaras and Transliteration](/concepts/aksaras).

## Canvas

A single image surface within an edition — typically one side of a fragment or folio. See
[IIIF and Deep-Zoom Images](/concepts/iiif).

## Canonical lemma

A headword in a reference language (Sanskrit or Pali) to which a Gāndhārī [lemma](#lemma) is linked.
See [Canonical Lemmas](/editor/canonical-lemmas).

## Collection

A grouping of related texts, usually by provenance, project, or repository. See
[Collections](/editor/collections).

## Edition

One scholar's reading of one witness to a [text](#text), tied to a set of manuscript images. See
[Editions](/concepts/editions).

## Grapheme

A written sign, or component of a sign, as distinct from the sound it represents. See
[Aksaras and Graphemes](/editor/aksaras).

## Lemma

The dictionary headword under which an attested form is filed. See [Lemmas](/editor/lemmas).

## Sequence

A grouping of tokens into a larger textual unit. See [Sequences](/editor/sequences).

## Text

A work, independent of any particular manuscript witness to it. See [Texts](/editor/texts).

## Token

A marked region of a manuscript image together with the reading assigned to it — roughly a word. See
[Creating Tokens](/editor/tokens).

## Transliteration

The representation of Kharoṣṭhī in Latin script using diacritics. See
[Aksaras and Transliteration](/concepts/aksaras).
